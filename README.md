# receptionist.today user issues

Public reporter-facing issue tracker for receptionist.today.

- Report a problem or request a change/feature.
- Do not include passwords, API keys, card data, private customer records, call recordings or other sensitive information.
- Every report is triaged as **fix**, **change**, **feature** or **unclassified**.
- Fixes and changes can be accepted by the team.
- **New feature requests require explicit approval or rejection by the product owner before engineering starts.**
- Internal engineering tickets, provider credentials and release details remain in the private platform repository.
- User-facing defects are P1 by default.

Use the **Report a user issue** form.
